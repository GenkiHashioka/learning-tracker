# 🚀 Learning Tracker (学習進捗管理アプリ)

フルスタック開発のスキルアップを目的として作成している、個人の学習記録・タスク管理アプリケーションです。

## 🛠 技術スタック

### Frontend
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

### Backend
- **Framework:** Hono
- **Language:** TypeScript
- **ORM:** Drizzle ORM
- **Database:** SQLite
- **API Communication:** Hono RPC (End-to-End Type Safety)

## 💡 特徴
- Hono RPCを用いた、フロントエンドからバックエンドまでの完全な型安全（Type-Safe）な開発環境
- Drizzle ORMによるスキーマ駆動開発
